## 사용 방법

7개 HTML 파일은 **UTF-8 BOM**으로 저장했습니다. 브라우저에서 파일을 직접 열 때 한글 인코딩을 명확히 인식하도록 하는 파일 시작 표시이며, 상품 내용에는 표시되지 않습니다. 편집기로 수정할 때도 UTF-8을 유지하세요. 이미 열어 둔 브라우저 탭은 새로고침하거나 파일을 다시 열어 주세요.

1. 해당 `.html` 파일을 텍스트 편집기로 열고 전체 내용을 복사합니다. 이미지 화면이나 브라우저의 소스가 아닌 파일 자체를 복사하세요.
2. 플랫폼에서 HTML 입력·가져오기를 지원하는 상세설명 편집 모드에 붙여넣습니다. 에디터의 지원 여부와 변환 결과는 실제 관리자 화면에서 확인해야 합니다.
3. 저장 전 모바일 미리보기로 이미지, 줄바꿈, 카드 여백을 확인합니다. 인라인 스타일을 단순화했지만 플랫폼별 정제·이미지 재호스팅 결과까지 보장하지는 않습니다.
4. 판매가·옵션·최소주문수량·수령 방법은 플랫폼 판매 설정에도 별도로 입력합니다. 원본의 확인된 가격이며, 등록 시 최신 가격과 일치하는지 재확인하세요.
5. 법정 식품 정보는 실제 제품 라벨을 확인한 뒤 플랫폼 상품정보 입력란에 별도로 등록합니다. 미입력 상태로 게시하지 마세요.

이미지는 `https://nothingmatters.co.kr/`의 현재 공개 이미지 주소만 사용합니다. 해당 서버의 접근 정책·파일 변경은 플랫폼 상세설명에도 영향을 줄 수 있습니다. 플랫폼에서 이미지를 업로드해 재호스팅할 경우 승인된 실제 사진만 사용하세요. 상세설명은 결제나 상담을 외부 채널로 유도하지 않습니다.

## Cafe24 서울체 공통 CSS 설정

HTML 조각은 아래 글꼴 순서만 지정하며, 외부 폰트나 스타일시트를 자체적으로 불러오지 않습니다.

```css
font-family: "SeoulNotice", "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;
```

Cafe24에서 서울체를 쓰려면 사용하는 디자인 스킨의 **공통 CSS**에 아래 선언을 한 번 추가하세요. 상품 상세설명 HTML에 `<style>`로 붙여넣는 용도가 아닙니다. 아래 주소는 현재 운영 사이트의 `assets/site.css`에서 사용 중인 서울알림체 WOFF2 주소입니다. 사용하는 스킨의 실제 공통 CSS 파일과 적용 범위는 관리자에서 확인하세요.

```css
@font-face {
  font-family: "SeoulNotice";
  src: url("https://cdn.jsdelivr.net/gh/projectnoonnu/2505-1@1.0/SeoulAlrimTTF-Medium.woff2") format("woff2");
  font-style: normal;
  font-weight: 500;
  font-display: swap;
}
@font-face {
  font-family: "SeoulNotice";
  src: url("https://cdn.jsdelivr.net/gh/projectnoonnu/2505-1@1.0/SeoulAlrimTTF-Bold.woff2") format("woff2");
  font-style: normal;
  font-weight: 700;
  font-display: swap;
}
@font-face {
  font-family: "SeoulNotice";
  src: url("https://cdn.jsdelivr.net/gh/projectnoonnu/2505-1@1.0/SeoulAlrimTTF-Heavy.woff2") format("woff2");
  font-style: normal;
  font-weight: 900;
  font-display: swap;
}
```

본문은 Medium 500, 강조는 Bold 700, 제목은 Heavy 900입니다. 영문 작은 라벨만 Arial / Helvetica를 사용합니다. SmartStore에서 외부 폰트가 제거되거나 공통 CSS 설정이 없는 로컬 파일에서는 Apple SD Gothic Neo → Noto Sans KR → 시스템 sans-serif 순서로 표시합니다. 해당 폴백 글꼴의 설치 여부에 따라 기기별 모양이 달라질 수 있습니다. 폰트 파일을 자체 호스팅할 때는 사용 허용 범위를 확인하고 `src`를 실제 업로드 주소로 바꾸세요.

## 공통 수동 입력·확인 항목

아래 값은 추정해 넣지 않았습니다. 실제 라벨과 운영 정보를 확인해 입력하세요.

- 중량, 원재료명, 원산지, 알레르기, 소비기한, 제조일, 영양정보, 제조원과 상품정보제공고시의 해당 값
- 실제 배송 가능 지역·방식, 택배 가능 여부, 배송 온도·배송비·출고일, 옵션별 가격과 판매 가능 상태
- 플랫폼 판매 옵션과 예약 픽업 조건의 일치 여부

맛 설명의 재료 표현은 제품 특징 소개이지 전체 원재료·알레르기 표시를 대체하지 않습니다. TERMINAL의 개봉 후 밀봉·고온/직사광선 주의는 해당 제품 원문만 근거로 사용했고, 다른 제품에 보관 기간이나 공통 보관 기준을 확장하지 않았습니다.

## 구성과 검수 범위

- 인라인 CSS만 사용하는 폭 100%, 최대 860px·좌우 패딩 16px 구성입니다. Hero·스토리·주문 안내·FAQ는 1열, 맛·캐릭터·사진 갤러리는 모바일에서도 2열입니다. `font-size:0` 컨테이너 안에 `display:inline-block;vertical-align:top;width:48%;margin:1% 1% 18px;box-sizing:border-box`를 사용하며, grid/flex·스타일 태그·미디어쿼리·JS는 없습니다.
- 흰 바탕 `#ffffff`, 본문 `#111111`, 보조 글자 `#6b6b6b`, 얇은 구분선 `#e7e4df`, 브랜드 라벨 `#ff6a00`을 사용합니다. 큰 섹션에는 테두리 박스·둥근 모서리·파스텔 배경을 사용하지 않습니다. 보통 위아래 38px 여백과 1px 구분선으로 나눕니다.
- H1은 36px/900, 섹션 제목은 30px/900, 작은 제품명은 20px/900입니다. 제목은 서울체 Heavy(900), 일반 본문은 14px/500·줄높이 1.7, 카드 설명은 12.5px/500입니다. 영문 라벨은 10.5px/700·자간 .12em입니다. ‘실제 사진 1’ 같은 가시 캡션은 제거하되 이미지 alt와 구매 구성 정보는 유지합니다.
- Hero 사진은 폭 100%, 최대 760px입니다. 이미지 원본 비율을 유지하고 8px 모서리만 사용합니다. Hero 한 장만 `loading="eager"`, 나머지는 모두 `loading="lazy"`, 모든 이미지는 `decoding="async"`입니다.
- COOKIE FLIGHT는 카드마다 ‘쿠키 사진 → 맛 이름 → 해당 맛 설명 → 개별 포장 사진’으로 배치합니다. 사진과 떨어진 4개 설명 블록·중복 영문 맛 라벨·짧은 중복 설명은 제거했습니다. 원문 맛 설명은 그대로 유지합니다. COOKIE CREW의 스카프 설명도 각 컬러 사진 아래로 이동했습니다.
- 브루키 대표 사진은 Hero로 옮겨 제품을 먼저 볼 수 있게 했습니다. 주문 준비 4단계는 사례 갤러리보다 앞에 유지합니다. 제목은 한글 단어 단위로 줄바꿈하며, 긴 단어는 화면 폭 안에서 줄바꿈됩니다.
- 상품별 색상은 얇은 상단/마무리 선이나 작은 라벨에만 사용합니다. COOKIE CREW의 오렌지·스카이·그린은 캐릭터 라벨에만 표시합니다. 페이지마다 하단 주문 안내 한 곳만 검정 배경·흰 글자로 구분하며, FAQ는 Q./A.와 얇은 줄만 사용합니다.
